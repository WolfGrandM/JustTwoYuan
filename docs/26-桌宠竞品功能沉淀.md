# 26 · 桌宠竞品功能沉淀

> 调研方法：两仓库源码实读（dsh-pet-src 全文档 + 鲸鱼挂件 README/源码结构）。调研目的：为锦鲤桌宠扩展（换肤/倒计时/播报/特效）与桌宠基础版的设计选型提供依据。

## 1. 两个竞品是什么

| 仓库 | 定位 | 形态 |
|---|---|---|
| **dsh-pet**（PC2005-cloud，npm 可装） | **完整桌宠框架**：一只住在 DSH 里的桌面宠物——100+ 段透明动画、物理交互（拖拽甩抛/碰撞/多屏）、碎碎念与对话、语音（说+听）、余额展示、待办、睡觉、工作状态联动；支持多开与自定义宠物种类（pet pack） | DSH web 浏览器 overlay / DSH 桌面应用透明置顶窗 / 独立模式（Windows 绿色包）三形态 |
| **DeepSeek-Balance-Whale-Widget**（MeteorNOX） | **余额记账挂件**：DSH web 右下角常驻小鲸鱼——API 余额 + 今日已用 + 每轮对话消耗 + 峰谷定价展示 + 模块化泡泡系统 | DSH web 右下角常驻挂件（另有 Codex 桌面版独立仓库，已迁出） |

两者都不是锦鲤要的「彩票桌宠」，但分别是「**桌宠框架**」与「**挂件泡泡系统**」两个维度的成熟参照——锦鲤桌宠的每个需求都能在其中找到现成实现模式。

## 2. dsh-pet 功能全沉淀（桌宠框架维度）

### 2.1 六大功能板块（FEATURES.md 口径）

| 板块 | 能力要点 |
|---|---|
| **余额展示** | 内置多服务商 + 自定义服务商；按剩余额度六档播动画（钱袋满溢→分文不剩，每 20% 一档）；周期自动查 + 手动查 + 右键菜单；每宠物独立开关 |
| **碎碎念与对话** | 碎碎念/对话各可配模型（失败自动退回当前对话模型）；每宠物独立人设；四种图片入口（选文件/截屏/拖拽/Ctrl+V，进 DSH 附件库）；回答配图（表情包目录+张数上限）；对话记忆（带几轮可配，窗口画线标出）；周期自动碎碎念 |
| **语音** | 双向：TTS 念出来（对话回复+手动碎碎念，音色/音量/总开关可配，气泡等语音播完再收）+ ASR 听你说（按住话筒/快捷键，转文字填输入框）；可接自己的服务（注册槽） |
| **工作状态联动** | 跟随 DSH 会话六档（思考/工作/整理/等待/成功/出错）切动画+状态气泡；气泡按当前工具/命令说具体的话（读文件/改文件/跑 git push 各有台词映射）；有任务清单优先显示清单项 |
| **待办事项** | 一句话+可选到期时间（自绘日历，分钟 5 分档）；未完成在前按到期排序、完成划线转绿；提醒节奏由宿主定时器驱动（24h→12h→4h→1h→20m→5m 递密；逾期 1 天内每 30 分钟）——**不需要页面常开**；数据落 todos.json |
| **睡觉** | 右键睡下：完全安静（随机动作/碎碎念/余额/待办/工作状态全不打扰）；按周期说梦话（人设+睡觉情景提示词）；睡姿多套可配（入睡/循环/醒来三段接力） |

### 2.2 三种运行形态与兼容面

- **DSH web 浏览器 overlay**（Chromium/Firefox，VP9-alpha 透明动画；Safari 需 HEVC .mov 素材）
- **DSH 桌面应用透明置顶窗**（Electron，桌面 app 内右下角）
- **独立模式**（Windows 绿色包，不依赖 DSH）
- Linux headless 自动检测无显示环境并降级；多显示器/异构 DPI/任务栏避让/竖屏全支持
- **对锦鲤的意义**：桌宠扩展的「播报只在有端在线时发生」——dsh-pet 的多形态覆盖与降级处理是现成范本

### 2.3 自定义宠物管线（MAKE-YOUR-OWN-PET，全流程可复现）

```
① AI 视频提示词（仓库自带配方，可灵/Runway/豆包，绿幕 16:9）
   → 每动作 10 秒绿幕视频（睡觉 = 入睡→循环→醒来三段接力，帧连续性规则有专文）
② 素材链（Python+ffmpeg+numpy+scipy）：绿幕 HSV 自动抠像 或 PR 手工抠像 → 归一化 → 转码
②.5 Safari/HEVC .mov 变体（Release 固定 tag）
③ webm 进插件包 → dsh plugin add
```

→ **锦鲤专属形象（一只锦鲤主题的桌宠）可以走这条管线生成**——这是「换肤」需求的完整解法。

### 2.4 对外接口（其他插件驱动桌宠——对本项目最关键的部分）

- **HTTP**（`/dsh-pet-7340` 前缀，只监听本机、无鉴权）+ **Cordis 服务**（页面内 `ctx.get()` 零网络）双通道
- **读状态**：`/state`（长轮询唯一数据源）、`/config`、`/models`、`/chat?pet=`（对话记忆窗口）
- **占用锁**：`POST /lock`（联动演出期间独占——桌宠全静音让路；用户拖拽/隐藏立即撤锁=用户优先）
- **让它说话**：`/whisper`（模型生成一句）、**`/broadcast`（第三方投喂文本——外部给定内容写进气泡，不生成只搬运）**、`/bubble/clear`、`/chat`（带记忆对话，可带附件）
- **让它做动作**：`/anim`（点播池内动画或第三方 url）、`/position`（归一化坐标+弹簧模式）、`/throw`（抛掷物理）、`/sleep`/`/wake`
- **锁纪律**：需锁接口必须带 `?lock=<lockId>`；编号不对回 `lock-lost`（含 cause：过期/已释放/被用户抢走）

→ **锦鲤桌宠扩展四项需求的映射**：中奖播报 = `/broadcast`（外部文本投喂，不生成）；倒计时 = `/broadcast` 定时投喂（或待办提醒机制）；特效 = `/anim` 点播；换肤 = pet pack 管线。**四项全部有现成承载。**

## 3. DeepSeek-Balance-Whale-Widget 功能沉淀（挂件泡泡系统维度）

### 3.1 记账与显示

- 常驻自启（标准 DSH bundle）；余额 60s 自动刷新+手动；数字滚动动画；网络抖动沿用最近余额不报错
- **两种取数**：凭据 `DEEPSEEK_API_KEY` 优先 / DSH 账号登录态兜底（不需要建 key）
- **小鲸鱼记账**：余额下降=消费、上升=充值/赠金单独记录不冲掉；「待核对余额调整」提示+余额校正；8 位小数记账、明细 90 天/2 万条、逐日归档 365 天
- **每轮对话消耗**：监听本机会话事件，按模型真实 usage（input/cache/output/reasoning）换算金额，每轮弹消耗泡泡（可开关/自动关秒数/内容模块化自定义 `{cost}` 占位）
- **峰谷定价**：工作日高峰/周末谷价，状态文字+倒计时+多样式
- **用量记录窗口**：今日/近 7 天/全部；模型占比条；按日期展开明细；按日期/模型名搜索；友好模型名标注

### 3.2 泡泡系统（核心——锦鲤播报样式可直接参照）

- **点击序列**：首次点击泡→再次点击队列（任意增删排序，两泡 A/B 加权轮抽）
- **点按推进队列**（可选）：点一下角色=推进一项，走完收起
- **模块化内容**：泡泡 = 若干模块按行组成——文本、超链接、随机语句（带权重不连续重复）、图片/动图（独占一行）、随机图片（带权重）、余额类内置数值模块（总余额/赠金/充值余额/今日已用/峰谷时段/对话名——可调保留长度截断）
- **逐模块样式**：字体/字号/加粗斜体下划线/纯色或跑马灯渐变/底色；文本悬浮快捷编辑
- **拖拽排版**：桌面原生拖拽、移动端长按拖拽；并行/拆行/整行排序；每行 ≤6 模块、泡泡 ≤6 行，图片模块独占一行
- **模块库**：常用模块「另存」复用

### 3.3 交互

- 四边吸附（比例/像素、角落组合、可关闭）、贴左水平镜像翻转、按压 Q 弹、可隐藏菜单按钮（右键/长按唤出）、移动端触摸拖动+长按 0.4 秒拖拽排序、全局气泡开关+按压泡泡设置

### 3.4 工程细节（值得抄的坑）

- 余额瞬时抖动自动沿用最近余额不报错；「已观测消费」与「余额校正」分账；账本精度 8 位小数记、显示两位
- 菜单底部版本行「不改变菜单高度」的布局处理（按钮下边距与菜单下内边距各让出等高）
- 移动端触摸接管（不把页面手势判成滚动导致拖不动）；长按 0.4 秒进入拖拽排序
- iOS/Safari 兼容策略：webm alpha 不认 → HEVC-with-Alpha .mov 官方转码素材按需放入

## 4. 对锦鲤桌宠的映射（需求→承载方式）

| 锦鲤桌宠需求（待办池） | dsh-pet 承载 | whale 挂件承载 |
|---|---|---|
| 换肤 | **pet pack 管线**（MAKE-YOUR-OWN-PET 全流程：AI 视频配方→绿幕抠像→透明动画→pet pack）——锦鲤专属形象 | 挂件换肤无此概念 |
| 每日播报昨日中奖结果 | **`/broadcast` 第三方投喂**（koi 战果事件 → 桌宠气泡播报，不生成只搬运） | 泡泡系统（但 whale 挂件与 koi 无事件对接） |
| 停购倒计时弹窗 | `/broadcast` 定时投喂 或 待办提醒机制（24h→20m 递密节奏现成） | — |
| 奖级特效 / 接近度播报 | `/anim` 点播动画 + `/broadcast` 文本（不同奖级配不同动画） | — |
| 基础通知（未读/冒泡） | koi 现有简易气泡（已上线）或升级为 dsh-pet 桌宠 | — |

**集成架构结论**：锦鲤桌宠的正确路线 = **安装 dsh-pet 作为桌宠底座（npm：`dsh plugin add dsh-pet`，标准 DSH bundle）+ koi 作为内容提供方经其 HTTP/Cordis 接口驱动**——
1. 中奖播报：koi 战果事件（won=true）→ `/broadcast` 投喂桌宠气泡（文本+可配图）
2. 倒计时/每日播报：koi 定时器 → `/broadcast`
3. 锦鲤专属形象：MAKE-YOUR-OWN-PET 管线生成 pet pack（可选，二期）
4. koi 现有简易气泡保留为「未装 dsh-pet 时的降级显示」

**备选路线**（若不想依赖第三方插件）：参照 dsh-pet 的实现模式自研（client.js 内 slots 挂载 + 动画资产按其规范组织）——成本高一个量级，仅当 dsh-pet 停止维护或深度定制需求出现时再议。

## 5. 风险与依赖

| 项 | 说明 |
|---|---|
| 第三方依赖 | dsh-pet 为 PC2005-cloud 的 npm 包——版本锁定策略须定（市场版零依赖纪律的例外需 ADR）；上游停更风险 |
| 渲染面 | 桌宠动画在浏览器/桌面端渲染——服务器侧开销极小（仅 API 注册），但**渲染需要 web 界面开着**（浏览器 overlay）或桌面客户端；服务器无头部署时桌宠只在有端连上时可见（提醒会等端连上再补——与 whale/锦鲤场景一致的既有模式） |
| 市场版边界 | dsh-pet 若进锦鲤的市场包，属第三方依赖引入——BC-103 零 QQ/零凭证不受影响，但 hygiene 门与版本锁定需 ADR |
| 锦鲤形象素材 | pet pack 需要 AI 生成锦鲤动画（豆包/可灵配方现成）——素材制作是主人的工作量（或接受通用形象） |
