## 3. 问题清单（按痛度降序）

> 痛度排序依据：是否已在实机咬人 / 是否挡住后续重构 / 修复风险与收益比。每条含六要素 + 冻结区判定。**判定口径：ADR-0005「冻结 = 语义不变，非代码不变——允许重构内部，不许改行为」。**

### P1（痛度最高）client.js 双源维护已产出真实潜伏缺陷；内联副本与 lib/ui-logic.js 漂移无全量门

- **证据**：
  - 内联副本本体：`lib/client.js:602-686`（`exports.__uiLogic = {…}`，含 WIZARD_STEPS/LEARNING_COPY/UPLOAD_HINT/VERDICT_CALIBER/PENDING_LLM_NOTE/FULLBACKFILL_CONFIRM/SPORTTERY_DEEP_NOTE + 12 个函数）；权威源 `lib/ui-logic.js`（同名单导出）。client.js:12 注释自认双源（「工厂无法 import ESM」）；ui-logic.js:3 同。
  - **已发生的漂移（执行验证）**：`lib/client.js:130` 的引导气泡条件 `!guideSeen && !latest`——`latest` 在 KoiPet 作用域与工厂作用域均未定义（全文件 grep 仅 130 行与 342 行 `b.latestIssue` 两处命中）。微桩执行 `KoiPet()` 实测抛 `ReferenceError: latest is not defined`（首次运行、guide 未看过时必触发；guideSeen=true 时短路侥幸不炸）。
  - 等价门只有抽样：`tests/market-ui.test.mjs:159-170` 仅断言 WIZARD_STEPS/unreadCount/degradeDecision/verbosityChoice/wizardComplete/bubbleTitle 六项；常量类 LEARNING_COPY/UPLOAD_HINT/VERDICT_CALIBER/PENDING_LLM_NOTE/FULLBACKFILL_CONFIRM/SPORTTERY_DEEP_NOTE 与函数类 rejectedNote/ruleDupHint/verdictTextOf/uploadFormatOk/formatBytes/uploadEstimate/backfillProgressText/jobBadgeText 等 **14+ 成员无等价断言**。
- **动机**：MD-21 双维护是 docs/20 §7.2 点名的消除对象；`latest` 缺陷证明漂移不只是理论风险——它已经在交付面（桌宠引导气泡）上炸。
- **影响面**：client.js（736 行，桌宠 + 设置节全部 UI）；ui-logic.js；tests/market-ui + market-copy。
- **风险**：`latest` 修复属行为修复（直修轨性质），重构批若顺手夹带会违反「行为保持」边界；不修则每次首次运行用户都踩。双源若只扩测试不治本，维护成本继续按成员数线性增长。
- **预期收益**：漂移归零（机械门）；`latest` 缺陷显式登记交主人裁决通道；client.js 后续可安全动。
- **冻结区/ADR**：不触碰（FZ-6 是 API 形状、FZ-7 是围栏语义，本条纯 UI 源码治理；`latest` 修复建议走 docs/18 直修轨 TF 条目）。

### P2 浏览器加载链路（exports→roster→combo）三腿全部零测试覆盖——ADR-0005 已记录的血教训尚未关账

- **证据**：
  - 链路三腿：`package.json:23-27`（exports `./client` → lib/client.js）；`cordis.patch.yml:11-13`（bundle patch insert，注释自警「name 必须与包名完全一致，否则『装上了但面板 404』」）；宿主 roster/combo（仓外）。
  - 实际咬人一次：git commit **545f491**「fix(dsh-koi): 补 package.json exports 的 ./client 映射——dsh-client-modules 按 exports["./client"] 解析浏览器端模块，缺失时按 MissingClientBundleError 静默跳过——面板『设置 → 彩票』因此从未出现」。docs/20 §4 与 ADR-0005 §4 均已登记「部署后必开一次面板」。

- **风险**：补的是**静态属性测试**（文件存在、exports 指向存在文件、patch name === 包名、client.js 挂载 id === 包名），不覆盖宿主运行时行为——不能宣称「链路已测」，只能把 545f491 这一类破坏在本地拦住。

### P3 scheduler.js 体积与职责过载（917 行 / 15 个 export / 31 个函数 / 17 个依赖）+ 两条循环 import 的根在这里

- **影响面**：scheduler.js、events.js、drawstore.js、tests/v11-fixes + market-scheduler + market-events + market-drawstore 的 import 路径。

### P5 配置三入口读取不等价（FR-1020「三入口等价」存在一个反例）

- **证据**：未迁移的 v1 配置（有 `games` 无 `modes`）下，调度器与 CLI 读到换算后的 modes（config.js:74-85），而 `index.js:190`（GET /api/config）与 `:196`（POST /api/config 的 current 基线）用裸 spread——POST 校验会报「modes 缺失」拒绝，GET 返回无 modes 的形状；同一份配置、同一时刻、三个入口两种口径。
- **动机**：docs/15:147 FR-1020（市场版 IR 权威）承诺「配置文件/CLI 等价路径（同一份配置与校验规则）」+ docs/10 §5.1 配置数据契约；client.js:597 页脚还向用户宣传「配置三入口等价」。

- **冻结区/ADR**：FZ-6 不触碰（config 路由是市场版加法路由，非既有 4 条；形状不变，值域在 v1 遗留场景修复）。
