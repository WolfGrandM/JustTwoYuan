## 1. 隔离原则（硬约束）

- 代码：`/opt/dsh-plugins/dsh-koi-canary`（本地 0.4.0+v0.2 重构构建，版本升 0.4.1）
- 隔离 home：`/home/dsh/.dsh-canary`（模型配置从生产复制，其余全新——koi 数据/配置/事件全隔离）
- profile：从生产 web 复制后**裁剪**——bundles 只留 `dsh-base + dsh-web-app + dsh-koi`（去掉 onebot/鲸鱼/humanism/m：**canary 零 QQ 零干扰**）；dsh-koi 依赖指向 canary 目录 link
- 进程：`DSH_HOME=/home/dsh/.dsh-canary dsh web --no-open --port 3081`（dsh 用户，nohup）
- 生命周期：明天（周六，三彩种全开）跑一期完整流程后**停进程**，晋升决定归主人
