# 规则库（硬约束 / 走线友好 / 软评分）

> **用户修订（2026-10-24，效力高于下文冲突条款）**：
> 1. 配电箱、电位孔规格/容量/延线等一切电力配件与走线问题**由电工统一考虑，布局不建模、不判定、不预留净空**（H3/H7 及电气内检暂停执行；电位孔仅作图面参考点）。
> 2. 展示台功能灵活：可作临时工位与杂物放置台，4 张桌允许分散布置。
> 3. 东南门常闭、平常不开：不再要求两门间 120cm 连通主廊；东南门仅保留门回转净空与基本到达通道（≥80cm 次通道）。
> 4. 工位单元改为**用户方案**：标准桌两两对拼（背靠背合拢、人对坐）×3 对 = 6 座大桌（240×120），**短边贴墙半岛布置**，两条长边各留 1.5m。

分三档：**H 硬约束**（任一 ERROR 即布局不合格，必须迭代修复或显式标注豁免）；**W 走线友好**（内部校验指标，不进交付物）；**S 软评分**（候选对比用）。标 ⚙ 的数值是默认参数，P1 用户确认或电工反馈后可改，改后记录在 `data/room.json → meta.calibrated_params`。

## H 硬约束清单

| # | 规则 | 判定 |
|---|---|---|
| H1 | 全屋占地率 ≤75% | Σ(家具外接矩形面积)/房间面积；椅子按工位数计投影（45×45⚙/椅，只对有座工位计） |
| H2 | 家具均在墙内皮内、互不重叠 | 矩形包含 + 两两相交检测（tolerance 1cm） |
| H3 | 每工位供电可达 | 工位到某现有电位孔的**可行延线距离** ≤500cm⚙ 且该孔剩余容量足够；否则该工位必须带 `需电工确认` 标注（带标注算"有条件通过"，进 P4 兜底） |
| H4 | 椅后起身空间 ≥60cm | 沿 seat_dir 方向、桌面外缘起 ≥60cm 净空（不得被其他家具投影占用；允许与通道重合） |
| H5 | 主通道净宽 ≥120cm⚙，次过道 ≥80cm⚙ | 房间自由区域做 120cm 圆盘/矩形扫描；两门之间必须存在 ≥120cm 宽连通廊道（疏散） |
| H6 | 门开启回转区净空 | 门扇扫过扇形（半径=门宽，含铰链侧）+ 门外开时门口 30cm⚙ 通过带，不得被家具投影占用 |
| H7 | 配电箱前方 100cm 净空 | 配电箱位置沿法线方向 100×箱宽⚙ 矩形内无家具 |
| H8 | 设备操作/检修面 ≥60cm⚙ | 每台设备台的主操作面（长边侧）外 ≥60cm 净空 |
| H9 | 高物避窗 | h>120cm 的家具（架子等）不得进入任何窗洞口在地面上的投影带（窗位±10cm⚙）；架子贴墙时优先窗间墙垛 |
| H10 | 杂物/存储不占通道与预留区 | storage、buffer 类家具不得与 corridor / 门回转区 / H7 净空 / 休闲与展示的 zone 重叠 |
| H11 | 分区需求满足 | 研究生 6 工位在西墙窗带单排；休闲区 8–12㎡ 在东墙北门附近；展示区 4 桌在南门侧；buffer 3–5㎡ 在架子附近 |
| H12 | 每工位有对应插座标注 | 每个 seat 型 placement 必须能映射到：某电位孔 id / `16A预留` / `需电工确认` 三者之一 |

## 电气内检（配套 H3/H12，不产正式文件）

- 常开负载 = 饮水机（CSV 修正：设备台 500W 但**不常开**，不计入常开，只计配电位）。
- 需用系数：在室 ≤10 人，工位负载按同时率 0.5⚙ 折算。容量模型（P1 默认，OQ2 未答复）：1 个 10A 五孔电位 = **2 位 × 每位 ≤4 工位（走线槽+排插×2 带过载保护）= 最多 8 工位/孔**，且每位折算功率 ≤1500W⚙。工位估算负载 120W/位（笔记本+显示器）。
- 饮水机占 P-E1 一位；16A 预留位只做预留不接负载但占位；设备台各占 P-E2 一位。
- 行供电模型：连续桌行由**行端一点馈电**（馈点=行端到孔的可行延线 ≤500cm⚙），行内经走线槽分接不限距；无法满足的行/工位标注"需电工确认"。

## W 走线友好指标（内部校验）

| # | 指标 | 计算 |
|---|---|---|
| W1 | 干线转弯数 | 从配电箱沿墙(墙脚 30cm⚙ 带)到每个被引用电位孔的折线路径，统计 90° 转弯次数求和；越少越好，报告逐条列出 |
| W2 | 对齐率 | 同组同规格家具：可两两对齐的边中实际对齐（±2cm⚙）的比例；≥0.8⚙ 为"成行成排"达标 |
| W3 | 岛朝向 | 每个工位岛的长轴方向应 ⊥ 其进线方向（进线方向=最近电位孔所在墙的法线）；逐岛判定 pass/fail |
| W4 | 压线冲突 | 贴墙且进深 ≥50cm 的高物（架子/柜）落在墙脚 30cm 线管带内的冲突计数，目标 0（桌类腿间可走线不计） |

判定汇总：W1 无离群簇 + W2 达标 + W4=0 视为"走线友好"，否则在候选说明里写明风险点交 P4 复核。

## S 软评分（每候选一张评分卡，10 分制）

| # | 维度 | 权重 | 打分锚点（0–10） |
|---|---|---|---|
| S1 | 采光均匀度 | 0.20 | 各分区中心到最近窗的距离归一化后取负加权平均；研究生区已锁定西窗不参与分配，其余分区距窗越均匀越高分 |
| S2 | 工位朝向 | 0.25 | 侧窗而坐=10；背窗=7；无窗向=6；面窗（西晒直射屏幕）=4。按工位平均 |
| S3 | 公共点步行距离 | 0.25 | 各工位到休闲区中心与较近一樘门的曼哈顿距离，归一化（以最差候选为 0，最好为 10） |
| S4 | 开放感 | 0.20 | 入口视线廊道（门到房间对角方向的净空带宽）+ 中心区留白面积占比，经验映射 0–10 |
| S5 | 噪音隔离 | 0.10 | 设备区/休闲区到最近工位组的距离（≥300cm=10，0cm=0 线性）；权重低，功能交叉没关系 |

总分 = Σ(单项×权重)。评分卡同时列出 W 指标与 H3/H12 的"需电工确认"工位数，供用户选型时一并看到。

## 冗余与分配策略（软规则，冲突时按序让位）

1. 杂物增长吸收顺序：架子（垂直空间）→ 空余桌面 → 地面缓冲区；缓冲区不得被前两者提前占满。
2. 空余桌椅先满足研究生组 6 工位，剩余才允许作杂物台面。
3. 组间紧凑优先（相邻组贴邻摆放可接受），不为软评分牺牲紧凑性。
4. 存储件（架子/柜）填缝收尾：优先窗间墙垛、角落、非通道墙面。
