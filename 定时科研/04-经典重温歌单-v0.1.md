## 第一章 · CNN 与检测前史（6 篇）

这一章讲深度学习接管视觉的奠基年代：残差连接让骨干可以无限加深，YOLO 把检测变成一次前向的回归问题，FPN、Focal Loss、SENet 分别奠定了检测的多尺度骨架、单阶段训练学与通道注意力。它们是后面四章一切讨论的"方言基础"——不懂这一章，读不懂任何现代检测器的配置表。

**01 · ResNet（2015）**【白名单例外 · Q2】
- 标题：Deep Residual Learning for Image Recognition
- arXiv：[1512.03385](https://arxiv.org/abs/1512.03385)
- 历史地位：残差学习与跳跃连接让百层以上网络可训练，是深度学习时代被引最多的架构论文，此后一切骨干的默认构件。
- 与哨位的关系：视觉骨干谱系的零点刻度——Darknet-53、CSP 结构乃至 Transformer 块里的残差连接都是它的后裔。

**02 · YOLOv1（2015）**【白名单例外 · Q2】
- 标题：You Only Look Once: Unified, Real-Time Object Detection
- arXiv：[1506.02640](https://arxiv.org/abs/1506.02640)
- 历史地位：把目标检测重构为单次前向的统一回归问题，开创"实时检测"整个品类。
- 与哨位的关系：哨位第一关键词族（YOLO 系）的起点——歌单中另有七篇 YOLO 系条目（第一章的 YOLOv2 与第四章 v3 至 v10 六篇代际），皆自它发端。

**03 · YOLOv2 / YOLO9000（2016）**
- 标题：YOLO9000: Better, Faster, Stronger
- arXiv：[1612.08242](https://arxiv.org/abs/1612.08242)（v1：2016-12-25，已核验）
- 历史地位：anchor 机制 + BN + 高分辨率微调的训练配方，加 wordtree 联合训练到 9000 类，YOLO 从概念验证变成工程可用的检测器。
- 与哨位的关系：YOLO 系工程范式的定型作；其检测-分类联合训练思路是今天开放词表检测（YOLO-World 一系）的远祖。

**04 · FPN（2016）**
- 标题：Feature Pyramid Networks for Object Detection
- arXiv：[1612.03144](https://arxiv.org/abs/1612.03144)（v1：2016-12-09，已核验）
- 历史地位：自顶向下旁路 + 横向连接的多尺度特征金字塔，成为此后几乎所有检测器的标准颈部。
- 与哨位的关系：读任何现代检测器（含 YOLOv3 之后的多尺度检测头）都绕不开的骨架词汇。

**05 · RetinaNet / Focal Loss（2017）**
- 标题：Focal Loss for Dense Object Detection
- arXiv：[1708.02002](https://arxiv.org/abs/1708.02002)（v1：2017-08-07，已核验）
- 历史地位：focal loss 化解单阶段检测的正负样本失衡，单阶段精度首次超越两阶段。
- 与哨位的关系：单阶段训练损失设计的分水岭，YOLO 系后来的标签分配与损失改进都在与它对话。

**06 · SENet（2017）**
- 标题：Squeeze-and-Excitation Networks
- arXiv：[1709.01507](https://arxiv.org/abs/1709.01507)（v1：2017-09-05，已核验）
- 历史地位：通道维度的"挤压-激励"即通道注意力，ImageNet 2017 冠军，把"注意力"一词写进 CNN 骨干设计。
- 与哨位的关系：哨位"attention 变体"关键词在 CNN 时代的原点，CBAM、ECA 等 YOLO 常客模块的共同祖先。

## 第二章 · attention 与 Transformer（5 篇）

这一章讲注意力如何从 CNN 的外挂模块（上一章的 SENet、下一章前夜的 Non-local）升格为独立架构：Transformer 证明"只要注意力就够"，BERT 与 GPT-3 证明预训练与规模的力量，FlashAttention 解决注意力的工程效率。此后视觉侧的每一步，都是把这套语法移植到像素上。

**07 · Transformer（2017）**
- 标题：Attention Is All You Need
- arXiv：[1706.03762](https://arxiv.org/abs/1706.03762)
- 历史地位：完全基于自注意力的编码器-解码器，弃循环弃卷积，成为此后所有模态的通用底座。
- 与哨位的关系：哨位"transformer 及替代架构"关键词的参照系原点——后面四章的每篇都在与它对话。

**08 · Non-local Networks（2017）**
- 标题：Non-local Neural Networks
- arXiv：[1711.07971](https://arxiv.org/abs/1711.07971)（v1：2017-11-21，已核验）
- 历史地位：把自注意力作为可插拔模块引入卷积网络，首次在视觉任务上实证长程依赖建模的收益。
- 与哨位的关系：CNN 与注意力之间的桥——从它到 ViT，只差"把 CNN 去掉"这一步。

**09 · BERT（2018）**
- 标题：BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding
- arXiv：[1810.04805](https://arxiv.org/abs/1810.04805)
- 历史地位：掩码预训练 + 微调范式确立，序列建模进入预训练时代。
- 与哨位的关系：视觉侧掩码预训练（第三章的 MAE）的直系思想来源；读 MAE 之前的前置篇目。

**10 · GPT-3（2020）**
- 标题：Language Models are Few-Shot Learners
- arXiv：[2005.14165](https://arxiv.org/abs/2005.14165)（v1：2020-05-28，已核验）
- 历史地位：1750 亿参数证明"规模 + 上下文学习"可换来零样本泛化，开启大模型时代。
- 与哨位的关系：解释了"骨干的可扩展性"为何成为架构评审硬指标——ViT 的 scaling 曲线与 Mamba 的线性复杂度都在回答它提出的问题。

**11 · FlashAttention（2022）**
- 标题：FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness
- arXiv：[2205.14135](https://arxiv.org/abs/2205.14135)（v1：2022-05-27，已核验）
- 历史地位：不改数学、只改访存策略的精确注意力实现，把长上下文的算力与显存墙大幅后推。
- 与哨位的关系："attention 变体"哨位的效率维度——一切"注意力太贵"的讨论（含 Mamba 的动机）都以它为背景板。

## 第三章 · ViT 与视觉 Transformer（8 篇）

这一章讲 Transformer 全面接管视觉：ViT 证明"大数据 + 纯注意力"的骨干可行，DeiT 解决数据效率，DETR 与 Deformable DETR 把检测查询化、RT-DETR 做到实时，Swin 给出层次化通用骨干模板，CLIP 与 MAE 补上语言监督与掩码预训练两条路线。这一章满编 8 篇，是哨位关键词密度最高的一段。

**12 · DETR（2020）**
- 标题：End-to-End Object Detection with Transformers
- arXiv：[2005.12872](https://arxiv.org/abs/2005.12872)（v1：2020-05-26，已核验）
- 历史地位：集合预测 + 二分匹配 + 对象查询，把检测做成端到端集合预测，废除 anchor 与 NMS。
- 与哨位的关系：检测框架谱系的另一半——YOLO 后续每个"去 anchor / 去 NMS"的决定都在回应它。

**13 · Deformable DETR（2020）**
- 标题：Deformable DETR: Deformable Transformers for End-to-End Object Detection
- arXiv：[2010.04159](https://arxiv.org/abs/2010.04159)（v1：2020-10-08，已核验）
- 历史地位：稀疏可变形注意力解决 DETR 收敛慢与小目标弱的痛点，成为检测 transformer 的默认底座。
- 与哨位的关系："attention 变体"与"检测框架"两条关键词的交汇点，RT-DETR 直接建在它之上。

**14 · ViT（2020）**
- 标题：An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale
- arXiv：[2010.11929](https://arxiv.org/abs/2010.11929)
- 历史地位：patch 序列 + 纯 Transformer，大规模预训练后超越 CNN，开启视觉骨干的 Transformer 纪元。
- 与哨位的关系：视觉骨干叙事的分水岭——此后所有新骨干（含第五章的 Mamba 系）都拿它当对照系。

**15 · DeiT（2020）**
- 标题：Training data-efficient image transformers & distillation through attention
- arXiv：[2012.12877](https://arxiv.org/abs/2012.12877)（v1：2020-12-23，已核验）
- 历史地位：蒸馏 token + 强增广让 ViT 摆脱私有巨量预训练数据，ImageNet-1K 上可复现地训出强 ViT。
- 与哨位的关系：视觉骨干"数据效率"的标尺；检测界常用的 ViT 预训练权重多出自 DeiT 系配方。

**16 · CLIP（2021）**
- 标题：Learning Transferable Visual Models From Natural Language Supervision
- arXiv：[2103.00020](https://arxiv.org/abs/2103.00020)
- 历史地位：4 亿图文对的对比学习预训练，把图像嵌进语言空间，零样本迁移成为现实。
- 与哨位的关系：开放词表检测（YOLO-World、Grounding DINO）的地基——检测哨位追踪的下游主线之一。

**17 · Swin Transformer（2021）**
- 标题：Swin Transformer: Hierarchical Vision Transformer using Shifted Windows
- arXiv：[2103.14030](https://arxiv.org/abs/2103.14030)
- 历史地位：移位窗口注意力 + 层次化设计，把 ViT 改造成检测分割通吃的通用视觉骨干（ICCV 2021 最佳论文）。
- 与哨位的关系：层次化骨干的设计模板——VMamba 的 SS2D、无数"给 YOLO 换骨干"的实验都以 Swin 为基线。

**18 · MAE（2021）**
- 标题：Masked Autoencoders Are Scalable Vision Learners
- arXiv：[2111.06377](https://arxiv.org/abs/2111.06377)（v1：2021-11-11，已核验）
- 历史地位：高掩码率 + 非对称编解码的掩码图像建模，把 BERT 式预训练成功移植进视觉。
- 与哨位的关系：视觉骨干预训练的主流路线，下游检测分割微调收益显著，是骨干评测的标配起点。

**19 · RT-DETR（2023）**
- 标题：DETRs Beat YOLOs on Real-time Object Detection
- arXiv：[2304.08069](https://arxiv.org/abs/2304.08069)（v1：2023-04-17，已核验）
- 历史地位：首个做到实时的端到端 DETR（CVPR 2024），混编码器 + IoU 感知查询选择，与 YOLO 同台竞速取胜。
- 与哨位的关系：检测框架哨位的"现在时"——YOLO 系与 DETR 系的合流处，下一章的 v10（及增补候选 v12）都拿它当对照。

## 第四章 · YOLO 系演进（6 篇）

这一章只收真正立下里程碑的 YOLO 代际：v3 定型多尺度形态、v4 把训练技巧系统化、YOLOX 完成 anchor-free 转向、v7 把梯度路径设计推向极致、v9 正面回答信息瓶颈、v10 终结 NMS。每一篇都改变了后续版本的默认配置。v5 与 v8 无 arXiv 论文、v6 偏工业发布，均不入正选（见文末增补说明）。

**20 · YOLOv3（2018）**
- 标题：YOLOv3: An Incremental Improvement
- arXiv：[1804.02767](https://arxiv.org/abs/1804.02767)
- 历史地位：三尺度预测 + Darknet-53，"YOLO 的现代形态"由此固定，此后所有版本的对照基线。
- 与哨位的关系：YOLO 关键词族的语法定型作，多尺度检测头的用法沿用至今。

**21 · YOLOv4（2020）**
- 标题：YOLOv4: Optimal Speed and Accuracy of Object Detection
- arXiv：[2004.10934](https://arxiv.org/abs/2004.10934)（v1：2020-04-23，已核验）
- 历史地位：CSPDarknet + PANet 颈部 + Bag-of-Freebies/Specials 训练学，单 GPU 可复现的 SOTA，社区可维护 YOLO 的转折点。
- 与哨位的关系：训练技巧系统化的范式确立者，后续版本的消融表格式承自它；CSP 结构从此进入每一代 YOLO 骨干。

**22 · YOLOX（2021）**
- 标题：YOLOX: Exceeding YOLO Series in 2021
- arXiv：[2107.08430](https://arxiv.org/abs/2107.08430)（v1：2021-07-18，已核验）
- 历史地位：anchor-free + 解耦头 + SimOTA 标签分配，把 YOLO 推进 anchor-free 时代。
- 与哨位的关系：YOLO 系现代化的关键一跳；今日"无 anchor 为默认"的局面由它参与定型。

**23 · YOLOv7（2022）**
- 标题：YOLOv7: Trainable bag-of-freebies sets new state-of-the-art for real-time object detectors
- arXiv：[2207.02696](https://arxiv.org/abs/2207.02696)（v1：2022-07-06，已核验，一作 Chien-Yao Wang）
- 历史地位：E-ELAN 可扩展梯度路径 + 模型重参数化 + 辅助头训练，刷新实时检测的精度-速度 frontier。
- 与哨位的关系：Wang Chien-Yao 团队（v9 作者）的上一站——理解 v9 的 PGI/GELAN，要先看 v7 的梯度路径设计。

**24 · YOLOv9（2024）**
- 标题：YOLOv9: Learning What You Want to Learn Using Programmable Gradient Information
- arXiv：[2402.13616](https://arxiv.org/abs/2402.13616)（v1：2024-02-21，已核验，一作 Chien-Yao Wang）
- 历史地位：可编程梯度信息（PGI）+ 广义高效层聚合网络（GELAN）正面回答深层网络的信息瓶颈问题。
- 与哨位的关系：主人的口味锚点论文；其作者团队已是哨位的重点作者监控对象（纪要 §3 反馈示例）。

**25 · YOLOv10（2024）**
- 标题：YOLOv10: Real-Time End-to-End Object Detection
- arXiv：[2405.14458](https://arxiv.org/abs/2405.14458)（v1：2024-05-23，已核验，NeurIPS 2024）
- 历史地位：一致性双标签分配使 NMS 可彻底移除，YOLO 首个全程端到端的版本。
- 与哨位的关系：YOLO 系与 DETR 系在"去 NMS"上的会师点，检测框架演进哨位的关键节点。

## 第五章 · SSM 与新骨干（5 篇）

这一章讲"注意力之外"的新骨干：S4 从控制论的状态空间模型出发解决长程序列建模，Mamba 用选择机制与硬件感知算法把它推向实用，Vim 与 VMamba 把 Mamba 带进视觉骨干；ConvNeXt 则同时提醒我们——现代化之后的纯卷积仍是必须对表的基线。这是主人第二个口味锚点（Mamba）所在、也是当前最活跃的前沿。

**26 · S4（2021）**
- 标题：Efficiently Modeling Long Sequences with Structured State Spaces
- arXiv：[2111.00396](https://arxiv.org/abs/2111.00396)（v1：2021-10-31，已核验，ICLR 2022 Outstanding Paper HM〔荣誉提名〕）
- 历史地位：结构化状态空间模型（HiPPO 理论）的可训练实现，长程依赖序列建模的奠基作。
- 与哨位的关系：Mamba 谱系的理论起点，读 Mamba 之前的必备前置篇目。

**27 · ConvNeXt（2022）**
- 标题：A ConvNet for the 2020s
- arXiv：[2201.03545](https://arxiv.org/abs/2201.03545)（v1：2022-01-10，已核验）
- 历史地位：逐项现代化 ResNet（宏观设计到训练配方）追平 Swin，证明纯卷积骨干在 2020 年代仍有一战之力。
- 与哨位的关系：新骨干评测的"CNN 对照组"——评 Mamba 系视觉骨干时它是必列基线。

**28 · Mamba（2023）**
- 标题：Mamba: Linear-Time Sequence Modeling with Selective State Spaces
- arXiv：[2312.00752](https://arxiv.org/abs/2312.00752)（v1：2023-12-01，已核验）
- 历史地位：选择机制 + GPU 感知的扫描算法让 SSM 兼具类注意力表达力与线性复杂度，近年最有影响的新骨干。
- 与哨位的关系：主人的第二口味锚点；"transformer 替代架构（SSM/Mamba）"关键词族的核心篇目。

**29 · Vision Mamba / Vim（2024）**
- 标题：Vision Mamba: Efficient Visual Representation Learning with Bidirectional State Space Model
- arXiv：[2401.09417](https://arxiv.org/abs/2401.09417)（v1：2024-01-17，已核验，ICML 2024）
- 历史地位：首批纯 Mamba 视觉骨干，双向扫描 + 位置嵌入，证明无注意力的视觉骨干在分类、检测、分割上可行。
- 与哨位的关系：SSM 与视觉骨干两条关键词的交汇，"ViT 之外还有什么"的直接答案。

**30 · VMamba（2024）**
- 标题：VMamba: Visual State Space Model
- arXiv：[2401.10166](https://arxiv.org/abs/2401.10166)（v1：2024-01-18，已核验）
- 历史地位：交叉扫描机制（SS2D）把非因果的 2D 图像适配给 SSM，层次化通用视觉骨干，下游全面对标 Swin。
- 与哨位的关系：更贴工程"换骨干"路线的 Mamba 基线，检测框架实验里最常见的选择。
