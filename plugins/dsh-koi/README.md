# 锦鲤 dsh-koi（市场版）

让 DSH 里的 agent「锦鲤」在每个开奖日研究历史走势后出一注号：双色球 / 大乐透 / 排列三，
投注结构档位制、开奖后自动对账记模拟账本、通知走事件层与可插拔渠道（内置桌宠面板渠道）。
第二波起内置**本地全量开奖底座 + 学习拆卡入库 + 回测引擎**（见下）。

> 一句提前说透的实话（也是本插件的根命题）：**彩票每期开奖都是独立随机事件，
> 任何选号方法都不能改变中奖概率。** 本插件卖的是「有人认真研究过 + 按时送达 + 诚实记账」
> 这件事本身——账本按官方规则算到分，不粉饰，难看本身就是它存在的意义。
> 学习与回测同样如此：**结论可能证明技巧无效——多数技巧的结论会是「与随机无异」**，
> 这会如实记录、不会美化；回测结论不驱动任何自动行为。

## 安装（双 profile 通用）

- **桌面版**：在 DSH 桌面应用的插件市场安装 `dsh-koi`，装完即用。
- **服务器/自建**：`dsh plugin --profile web add <本包>` 后同样开箱即用。
- 两种形态同一份代码：调度跑在你的 DSH 宿主进程内，数据全部落在本地 `$DSH_HOME`（默认 `~/.dsh`），
  模型调用走**你自己 DSH 配置的模型**（插件不带任何专属 key）。
- 首次安装会写入默认配置 `$DSH_HOME/koi.config.json`（schemaVersion 2，零任何预置凭证）。

**装完的三步上手**：
1. 打开「设置 → 彩票」，每张彩种卡上有 **现在来一注**（零配置门槛，默认手动模式·不记账）。
2. 想要每期自动出号+对账？点 **开启自动模式（向导）**，五步走完即可（见下）。
3. 点 **测试通知** 确认通知链路通。

## 运行模式（每彩种独立三态）

| 模式 | 行为 |
|-|-|
| `manual`（出厂默认） | 不自动出号；「现在来一注」随时可用，推荐标「手动推荐 · 不记账」 |
| `auto` | 完整流水线：出号 → 事件通知 → 22:00 起对账 → 记账 → 战果通知 → 增量入库 |
| `off` | 不自动出号；「现在来一注」仍可用（标「加餐 · 不记账」） |

**任何模式下「现在来一注」都可用且永不记账**（永久基础层）。

### 自动模式向导（五步 + 四项门控）

通知渠道 ≥1 → 投注档位 → 出号时间（须早于该彩种开奖时刻）→ 诚实条款确认 → 数据就绪检查。
任一门控缺失都会被阻止并逐项指明（面板 / CLI 行为一致）。

**桌面运行如实告知**：自动模式要求开奖时段（出号窗 17:30–19:50、对账 22:00–23:30）应用处于运行状态；
关机/睡眠会错过，补跑窗口至 19:50 兜底一部分。想要全天候可自建服务器部署（同构安装）。

## 通知渠道与凭证

- 所有通知先成为**结构化事件**（重试 5 分钟间隔、分类终止线、超线转补发队列并加【补发】标注、
  22:30 心跳判定全渠道静默告警 + 面板常驻红标兜底）——渠道只做传输，增删渠道不改业务。
- **内置桌宠渠道**（`panel`）：设置→彩票节的事件横幅/列表 + 右下角小桌宠（可整体关闭，关闭不影响其他渠道）。
- **添加渠道**：把适配器文件（`<type>.js`，契约见 `lib/channels/`）放入 `$DSH_HOME/koi/channels/`，
  凭证写同目录 `<type>.config.json`（**凭证不进主配置文件**，面板/CLI 回显一律掩码）。
- 事件保留 90 天滚动清理，桌宠消息列表窗口最近 200 条。

## 配置（三入口等价：面板 / 配置文件 / CLI）

六大区：渠道凭证 / 角色数量（策略师 1–4）/ 预算权重（默认 150 万 tokens/周，70%/90% 预警 +
触顶降档链兜底）/ 力度四档（follow-host·economy·standard·turbo——**影响分析质量与 token 成本，
不影响中奖概率**）/ 详略两档（简洁 = 号码+合规字段；叨逼叨 = +≤100 字结构化摘要）/ 投注档位（换档下期生效）。
配置页实时显示**成本估算双显示**：「当前形态实际估算（不随阵容）」+「M3 满配投影（随阵容/权重，随 M3 编排器生效）」。

```bash
node tools/koi.mjs config get|set <path> [value]   # 与面板同一份校验
node tools/koi.mjs mode <ssq|dlt|p3> <off|manual|auto> [--time HH:MM] [--tier 档位]
node tools/koi.mjs channels list|test [index]
node tools/koi.mjs backbone status|pull|full|stop  # 本地开奖库（近期窗口按需 / 全量回拉底座）
node tools/koi.mjs ingest <file>|status            # 学习上传与任务列表
node tools/koi.mjs cards list                      # 卡片库（名称/彩种/信任级/状态/回测结论）
node tools/koi.mjs backtest run|gold               # 回测引擎（--smoke 随机数据本跑）
node tools/koi.mjs events list                     # 事件队列与失败原因
node tools/koi.mjs deps [--json]                   # 体检
```

## 数据自给与升级保留

- 开奖数据只来自官方两源（福彩官网 / 体彩官方接口），抓取经四项校验（期号格式/日期/号码值域/连续性）
  后入本地库 `$DSH_HOME/koi/draws/`——**抓过即入库，二次请求零网络**；社区镜像为默认关闭的预留位。
- **覆盖升级不影响用户数据**：市场包只替换包目录；你的配置、渠道凭证侧车、预测/账本/事件/开奖库
  全部在 `$DSH_HOME` 下与包目录天然隔离。
- 老版本（v1.1，作者私有形态）升级：`node tools/koi.mjs migrate-v2`（可 `--dry-run` 预演）——
  旧推送凭证一次性迁入渠道侧车，既有运行语义保持；预测/账本业务数据零触碰。

## 全量回拉底座（第二波）

- 面板「设置 → 彩票 · 数据」区，或 CLI：`node tools/koi.mjs backbone full [--game ssq]`（全量约 140–160
  请求、15–30 分钟，批间隔 2 秒；**可随时中止，断点保留**，重启续拉不重复请求）。
- 分页协议按源定型：福彩期号窗口 / 体彩 `pageSize=100 + pageNo`；错峰守卫 17:00–22:30 不开始、
  运行中跨入自动暂停待续（`--no-offpeak` 显式越过）；done 后自动全库连续性审计 + 同源抽样核验，
  断档只报告不自动补拉。**真实全量回拉永不自动执行**——只由你手动触发。
- 与学习/回测共用一把后台作业锁（backfill/ingest/backtest 三者互斥，任一时刻至多一个后台作业）。

## 学习（上传技巧 → 清洗拆卡 → 卡片库）

📚 **学习 = 严格回测检验**：上传的技巧会先清洗拆成卡片，再用你的本地全量历史逐一回测。
**结论可能证明技巧无效——多数技巧的结论会是「与随机无异」**，这会如实记录、不会美化。
学习影响的是「我们知道的多少」，不改变中奖概率。

- 三通道：面板「学习」区上传（支持 `.txt` / `.md` ≤20MB；PDF/EPUB 请先转为文本——暂不支持直接解析）；
  服务器目录投喂 `$DSH_HOME/koi-work/inbox/`；CLI `node tools/koi.mjs ingest <file>`。
- 清洗（剥图/OCR 噪声/断行/页眉页脚）全部代码级完成、零 token；上传面实时显示 token 估算（口径：字节/12）
  与周预算占比；清洗后超 20 万字符或估算超本周剩余预算会**如实拒收并说明**（请分卷上传）。
- 判重三态：与既有卡同义不入库；规则级疑似重复保守拒入（面板显示理由）；相近不同条件入库带指针。
- 拆卡环节失败 → 「待补」态可见，宿主恢复后自动重试，绝不静默丢弃；重跑先回滚本任务已写卡片（幂等）。

## 回测引擎（因子 = 预注册判据）

- 内置六件（奇偶比/和值区间/012 路/连号/冷热/遗漏）× 三彩种；卡片技巧可因子化为声明式 DSL
  （白名单指标 + AND 组合，不执行任意代码）自动注册回测。
- 口径恒拼：本地全量历史滚动回测 · 命中判据回测前预注册 · 基线=判据滞后自评满足率 ·
  单侧精确二项检验（α=0.05）。「与随机无异」= 命中率与随机基线无统计学差异。
- **开奖是独立随机事件，回测结论不改变中奖概率，也不驱动任何自动行为**（不改档位、不进出号提示词）。
- CLI：`node tools/koi.mjs backtest run [--game ssq] [--factor <id>] [--smoke]`、`backtest gold`（金样本自检）、
  `cards list`（卡片库与结论）。
