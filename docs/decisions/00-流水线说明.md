## 默认决策总原则（各阶段相同）

1. 本应向用户提问/请求确认的点：一律采用当阶段角色下的最佳推荐默认值继续执行；
2. 每个这样的决策逐条登记到当阶段默认决策记录（表格：编号 | 事项/问题 | 候选项 | 采用的默认值 | 选择理由 | 影响与后续可改点）；
3. 文档中的 `[[PH:...]]` 数值占位符按各占位符 `rec:` 建议值定值并登记；
4. 如实汇报：没验证的明说，不虚报完成；遇到自相矛盾或无法绕行的硬阻塞，如实记录并写明采取的绕行措施；
5. 全程不执行 git commit/push，不做服务器部署；全部改动留在工作区（`git diff baseline-v0` 看全量增量）。
