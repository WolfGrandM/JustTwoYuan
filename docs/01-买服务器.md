# 01 · 买服务器

## 先做一个决定

你的两个需求会互相拉扯：

| | 海外机器（香港/日本/新加坡） | 国内机器（上海/北京） |
| --- | --- | --- |
| YouTube | ✅ 直接访问 | ❌ 不通 |
| B站 | ✅ 大部分内容可看，少数番剧有地区限制 | ✅ 全通 |
| 未来接 QQ 官方机器人 | ⚠️ 没官方承诺，需实测 | ✅ 最稳 |
| 你 SSH 进去操作的流畅度 | 香港 20–40ms 很顺；美国 200ms 会卡 | 10–30ms |
| 备案 | 不需要 | 不需要（不加域名不开放 80/443） |

**结论：既然你要 B站 + YouTube，就选海外，优先香港。** 香港是唯一能两头兼顾的位置：到大陆延迟低，YouTube 和 B站 都通，以后接 QQ 也最有希望——真不行，第二阶段加一台国内小机器做中转就行，不影响现在这一台。

## 选哪个位置

| 位置 | 到大陆延迟 | YouTube | B站 | 评价 |
| --- | --- | --- | --- | --- |
| **香港** | 20–40ms | ✅ | ✅ 少数番剧限制 | **首选**，晚高峰会抖 |
| 日本 | 50–80ms | ✅ 秒开 | ✅ | 次选，线路稳 |
| 新加坡 | 60–90ms | ✅ | ✅ | 可选，略远 |
| 美国西海岸 | 150–250ms | ✅ | 慢 | 只图便宜时选 |
| 欧洲 | 200–300ms | ✅ | 很慢 | 不推荐，SSH 会难受 |

## 具体买哪家

价格是 2026-10 的公开报价，会变，下单前以官网为准。

| 商家 | 位置 | 配置 | 约价格 | 适合谁 |
| --- | --- | --- | --- | --- |
| **腾讯云国际站 轻量** | 香港 | 2核2G / 30Mbps / 40G | **¥50–70/月** | **首选**：中文控制台、支付宝付款、客服讲中文 |
| 阿里云国际站 轻量 | 香港 | 2核2G / 30Mbps | ¥50–70/月 | 同上，价格活动多 |
| Vultr | 东京/新加坡 | 2核2G / 55G | $12–18/月 | 按小时计费，随时删了重开，折腾党 |
| Hetzner | 德国/芬兰/美国 | 2核4G / 20TB 流量 | €6.49 起 | 极致性价比，但要外币卡、无中文支持 |
| 搬瓦工 | 美国 CN2 GIA | 1核1G | $49.99/年起 | 线路质量好，但配置低 |
| RackNerd | 美国 | 2核2G | $20–30/年 | 白菜价，但国内访问慢，SSH 都卡 |

**我的推荐：腾讯云/阿里云国际站 香港轻量 2核2G。** 理由很实际——支付和售后不用折腾外币卡，控制台中文，出了事有人问；延迟和线路对 dsh 这种「等模型回复」的负载完全够用。

预算敏感就 Hetzner（€6.49≈¥53/月，还是 4G 内存），但注册要外币信用卡或 PayPal，出问题只能看英文文档。

**别买的**：美国低价年付机（$20/年那种）。延迟 200ms+，你 SSH 敲命令都能感觉到卡，抓 B站 页面要等半天，省下的钱不够糟心的。

## 内存选 2G 还是 4G

看你要不要「真·开浏览器」：

- 只抓网页文字、搜索、读字幕 → **2G 够**
- 要跑无头 Chrome（真的点开 YouTube 页面、处理登录态）→ **建议 4G**，2G 会 OOM

先买 2G，真需要再升级（云厂商都支持在线升配）。

## 下单要点

1. **镜像选 Ubuntu 24.04 LTS 64bit**，别选带宝塔/WordPress 的应用镜像。
2. **登录方式选 SSH 密钥**；只能设密码的话，设强密码，装完换密钥。
3. **安全组只放行 22 端口**。不要开 80、443、3080——dsh 只监听本机，走 SSH 隧道。
4. 海外机不用备案，也不用加域名。
5. 记下公网 IP。

## 买完先验证

在 Windows PowerShell：

```powershell
ssh root@1.2.3.4
```

进去后：

```bash
lsb_release -a      # Ubuntu 24.04.x LTS
free -h             # 内存 2G / 4G
df -h /
curl -sI https://www.youtube.com | head -1    # 海外机应返回 200/301
curl -sI https://www.bilibili.com | head -1   # 应返回 200
```

两条 curl 都通，说明这台机器能满足你的内容访问需求。国内机器跑第二条会超时。

## 2G 内存加个 swap

```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
free -h
```

## 海外机器装 dsh 的两个小差别

1. **npm 源换成官方**（海外访问 npmmirror 反而慢）：
   ```bash
   NPM_REGISTRY=https://registry.npmjs.org bash install.sh
   ```
2. **顺手装 yt-dlp**（抓 B站/YouTube 的视频信息、字幕）：
   ```bash
   WITH_YTDLP=1 bash install.sh
   ```
   不装也能用，只是「读视频内容」时会退化成只能读页面文字。
