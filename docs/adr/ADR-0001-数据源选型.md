# ADR-0001 数据源：仅两个官方一手源 + 自拉底座 + 校验层

- 状态：已采纳（v1 起生效；市场版第二波扩为全量自拉底座）
- 日期：2026-10-25 回填入档（决策时间 2026-10-23 ~ 10-25）

## 背景

三个彩种的开奖数据是插件一切行为（出号参考、对账、回测）的事实根基。候选：官方接口直连 / 第三方彩票聚合站 / 作者侧镜像分发。第三方站假数据重灾区；作者镜像有法律与流量归属问题（主人明确「我的流量不能被用户共用」）。

## 决策

1. **白名单铁律**：仅两个官方一手源——福彩官网 findDrawNotice（双色球）、体彩 webapi gameNo=85/350133（大乐透/排列三，排列三取排列五前三位）。永不接第三方彩票站。
2. **访问姿势**：体彩接口必须带浏览器头（Referer/Origin/UA）否则回验证页；响应 GBK 但所需字段全 ASCII。
3. **自拉底座**（BC-105）：每个用户自己从官方源拉——一次性全量回拉（实测 12,776 期 / 166 请求 / 零反爬）+ 增量挂 22:00 对账（同一抓取双消费，零独立请求）+ 抓过即入本地库（学习/回测永不重复依赖网络）。CDN 仓库镜像降级为默认关闭的可选加速。
4. **校验层**（BC-104）：期号格式（DC-006）/开奖日期合理性/号码值域/连续性断档检测；不过关即拒用本期数据并留痕，绝不静默学入。
5. 全量回拉仅手动触发（CLI/面板确认框），分批限速、断点续传、错峰窗口暂停。

## 后果

- 正面：法律风险最小（作者不分发数据）、数据可信度最高（一手）、用户 IP 几乎不碰官方历史接口。
- 代价：首拉等待（15–30 分钟，一次性）；官方接口改版需跟随适配。
- 已知边界：体彩分页深翻已实测可用（79 页）；接口上限变化由新鲜度探针（>7 天 ✗）兜底暴露。
