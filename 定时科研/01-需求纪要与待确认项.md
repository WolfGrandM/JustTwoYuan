## 0. 一句话定位

**学术哨兵**：跑在腾讯 WorkBuddy 上的定时学术雷达——按哨位（关键词/作者/学科）每天巡视 ArXiv，把值得看的论文提炼成中文卡片（创新点 + 实验亮点），中午以日报推送到飞书，同时归档进可回查的研究日志。长期目标是沉淀出"自己的科研 agent"。

## 1. 背景与生态

- 主人是 CV 方向研究者，口味锚点：YOLOv9、Mamba、YOLO 系列、目标检测框架与骨干网络。
- 已有生态「大肥鱼」：阿里云服务器 24/7 跑 dsh，带 QQ 通道、锦鲤预测、鲸鱼插件。本产品**不**长在服务器上，而是长在 WorkBuddy（腾讯的 agent harness，积分制便宜，原生支持自动化定时任务）。
- 选 WorkBuddy 的原因：定时任务原生支持、免费模型可用（hy、star-step 等）、agent 能力即产品本体。

## 3. 系统结构（文字图）

```
【自动跑批】自动化任务（每天中午）
   └─ 读 sentinel/preferences.md（哨位 + 权重）
   └─ ArXiv API 检索当日新论文
   └─ LLM 相关性打分 → 过滤取 top 5–10
   └─ 提炼五段式卡片（top1 下载 PDF 深读）
   └─ 归档 sentinel/（md + papers.jsonl + manifest）
   └─ webhook 推飞书日报 ＋ 同步 bitable 知识库

【人工交互】专家「哨兵」（随时对话，同一技能同一档案）
   └─ 反馈："第 2 篇不相关" / "少推医学影像" / "重点关注 Wang Chien-Yao"
   └─ 查库："我看过哪些 Mamba 相关的"
   └─ 点单：手动补跑、点经典、临时调整哨位
```

**卡片模板（五段式）**：①一句话定位 ②创新点 1–3 条 ③实验亮点（摘要有数字就写，没有标"见原文"）④为什么推给我（关联哨位）⑤原文与代码链接。

**日报结构**：跑批状态行 → 今日深度卡 1 张 → 短卡 5–10 张（按相关分排序）→ 经典重温小栏目（节奏见 Q1/Q3）。

## 6. Plan B：dsh 插件（先备着，不今晚写）

- **触发条件**：M2 演习证明 WorkBuddy 任务无法访问外网（webhook 发不出），或积分消耗长期超预算。
- **形态**：Node 插件跑在大肥鱼服务器上，复用锦鲤已验证的定时 + LLM + 推送模式；产品逻辑（哨位、卡片、目录约定、反馈）原样平移，只换执行引擎。
- **为何今晚的草稿不白写**：技能文档本质是"方法论 + 提示词"，dsh 插件的提示词模块可直接复用，数据格式（jsonl）不变。
